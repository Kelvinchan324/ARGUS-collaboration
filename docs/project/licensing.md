# Licensing Guidance

The repository needs an explicit license before outside collaborators can safely
reuse ARGUS-owned code or hardware. Selecting one is a maintainer/business
decision, so the scaffold does not guess.

Consider licensing these categories independently:

- software and documentation
- original mechanical/CAD designs
- logos, product media, and datasets

Before importing an existing file, record who created it and whether employment,
university, sponsor, customer, or upstream terms affect ownership. Preserve all
upstream notices. A permissive upstream license does not make ARGUS the author of
the upstream work.

After a decision, add `LICENSE`, any hardware license file, and a short notice to
each imported component. This page is project organization guidance, not legal
advice.
