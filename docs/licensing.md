# Licensing Guidance

The repository needs an explicit license before outside collaborators can safely
reuse ARGUS-owned code or hardware. Selecting one is a maintainer/business
decision, so the repository does not guess.

Before importing a file, confirm who created it and whether university, sponsor,
customer, employment, or upstream terms affect ownership. Keep upstream license
notices and links in the relevant robot README.

After a decision, add a root `LICENSE` for ARGUS-owned software and, if needed,
a separate license for original hardware/CAD. This page is project organization
guidance, not legal advice.
