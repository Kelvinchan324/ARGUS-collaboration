# Verified visualization geometry

This directory contains only geometry copied byte-for-byte from
`Kelvinchan324/custom-robot-studio` at commit
`500db5bab1168a550ca7c17693e8d2ed24a5b5f1`.

| Platform | Files | Upstream source | Upstream revision | License |
| --- | ---: | --- | --- | --- |
| Pupper V3 | 18 STL files | `G-Levine/pupper_v3_description` | `1a3c8590189d3a406219d155f4177afc491a7d77` | MIT |
| Open Duck Mini v2 | 45 STL files | `apirrone/Open_Duck_Mini` | `b23317a485b3cec7d8417f352478778b3475173c` | Apache-2.0 |

`real-assemblies.json` records the exact placement and orientation used by the
source studio. `real-catalog.json` records part names and upstream source URLs.
The matching upstream license texts are in `licenses/`.

These are visualization meshes, not certified fabrication drawings. No geometry
is provided here for Robot-AR, Aloha Mini, Bimanual Bunker Mini or Unitree Go2.
The website deliberately leaves those CAD slots empty.
