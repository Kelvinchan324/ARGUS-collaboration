# ARGUS Hardware

This area is for original ARGUS mechanical/electrical designs that are necessary
to build or maintain the system and have passed ownership/licensing review.

For each assembly, include a README, revision, BOM, source CAD, neutral exports
where practical, manufacturing notes, and a preview image. Use Git LFS for binary
CAD. Do not add downloaded vendor assemblies when a source link is sufficient.

Planned assemblies include the cockpit, armrest, and foot-pedal controls.
