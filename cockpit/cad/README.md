# Cockpit CAD parts

These SolidWorks part files are the current ARGUS cockpit frame and seat
dimension references supplied by the project team.

| File | Purpose |
| --- | --- |
| `2020Altube_01.SLDPRT` | 2020 aluminium-profile part reference |
| `2020Altube_02.SLDPRT` | 2020 aluminium-profile part reference |
| `chair_dimensions.SLDPRT` | Seat and mounting dimension reference |

Before manufacturing, verify the latest hardware revision, material,
tolerances, fasteners, load assumptions and emergency-clearance requirements.
These parts are research references and are not a certified structural design.

Do not add SolidWorks lock files beginning with `~$`. Add assemblies, drawings
or exports only after the team confirms ownership and the file is required to
reproduce the cockpit.
